## 🚀 Featured Projects

<details>
<summary><b>🌊 TidelQ — AI-Powered Coastal Safety Platform</b> &nbsp; <img src="https://img.shields.io/badge/2nd%20Prize-Susegad%20Sprint%202026-6C3FD8?style=flat-square"/> <img src="https://img.shields.io/badge/225%2B-Developers-4A00E0?style=flat-square"/></summary>

<br/>

> A real-time coastal hazard safety system that fuses satellite data, weather feeds, and crowdsourced reports into a live 0–100 safety score, powered by LLM-based scoring and Vision AI — deployed and serving users.

<div align="center">

| Attribute | Details |
|-----------|---------|
| **Stack** | Next.js · PostgreSQL/PostGIS · Supabase · Mapbox GL JS · OpenAI · Google Cloud Vision API |
| **Scale** | Competed against 225+ developers · Live production deployment |
| **Performance** | Async scoring pipeline keeps report submissions fast under LLM load |
| **Security** | Supabase RLS + JWT auth for secure role-based access control |
| **Impact** | 2nd Prize, Susegad Sprint 2026 · Live at tidelq.onrender.com |
| **Repository** | [github.com/tusharvaskarsharmawork-svg/TidelQ](https://github.com/tusharvaskarsharmawork-svg/TidelQ) |

</div>

**What it does:**
TidelQ is an end-to-end LLM-driven coastal intelligence system. The scoring engine ingests satellite imagery, live weather data, and crowdsourced hazard reports, then uses OpenAI to synthesize a real-time 0–100 safety score per beach. Google Cloud Vision API handles automated image classification for submitted reports. Geofenced push alerts notify users of hazards near their location. The entire pipeline is asynchronous to maintain responsiveness under peak LLM inference load. Data integrity and access control are enforced through Supabase Row-Level Security and JWT-based authentication, ensuring that only authorized roles can submit or view sensitive reports.

<summary><b>🐝 StudyBee — AI-Powered Study Analytics Platform</b> &nbsp; <img src="https://img.shields.io/badge/1st%20Prize-Global%20GenAI%20Hackathon-6C3FD8?style=flat-square"/> <img src="https://img.shields.io/badge/50%2B-Submissions-4A00E0?style=flat-square"/></summary>

<br/>

> An intelligent Chrome Extension that tracks cross-site browsing behavior, classifies it by study intent, and uses Gemini AI to auto-generate weekly learning-pattern reflections — backed by a full Node.js/Express/MongoDB pipeline.

<div align="center">

| Attribute | Details |
|-----------|---------|
| **Stack** | JavaScript · Node.js · Express · MongoDB · Chrome Extensions API · Gemini AI |
| **Scale** | 1st Prize among 50+ submissions · Live at studybee-3ru4.onrender.com |
| **Performance** | Real-time cross-site activity tracking with zero user friction |
| **Security** | User session isolation · Secure data pipeline architecture |
| **Impact** | 1st Prize, Global GenAI Hackathon · AI-generated weekly study reflections |
| **Repository** | [github.com/tusharvaskarsharma/StudyBee](https://github.com/tusharvaskarsharma/StudyBee) |

</div>

**What it does:**
StudyBee addresses the core problem of students tracking *how* they study, not just *how long*. The Chrome Extension intercepts and classifies browser activity across all sites, categorizing sessions as productive study, distraction, or research. This behavioral stream feeds a Node.js/Express backend, persisted in MongoDB. Gemini AI then processes raw session logs to auto-generate human-readable weekly reflections — surfacing insights about study patterns, peak productivity windows, and distraction hotspots. The result is an actionable learning intelligence dashboard that runs entirely in the background.
